# Lumos: Let there be Language Model System Certification

Different folders in this repository present the code for the different certification RQs in the paper - https://arxiv.org/abs/2512.02966. 

1. `vlm_safety_expts/` is for Sec6.2 and 6.3, i.e., VLM safety certification experiments.
2. `beaver_privacy_spec/` contains the experiments and code for the privacy certification study on Beaver (Sec6.4).
3. `nl2lmspec/` contains the natural-language-to-Lumos tooling and experiments related to NL-to-DSL and NL-to-Python translation (Sec6.5). See the README in that folder for details about scripts and file structure.
